# **App Name**: HSE Digital Platform

## Core Features:

- Secure Authentication: User authentication supporting secure login and password management, with options for SSO integration.
- Customizable User Portal: A customizable user portal with drag-and-drop widgets that display key HSE metrics and data, tailored to different user roles.
- Dynamic Form Builder (AI): Form builder tool to create and manage dynamic forms for Dialogue Sécurité and Audit de terrain modules, including various input types, attachments, and predefined lists. The LLM uses reasoning to dynamically recommend relevant fields and validation rules based on the selected HSE topic.
- Automated Notifications: Automated email notifications for deadlines and unvalidated actions, with a full history of notifications for auditing purposes.
- Access Control Management: Role-based access control with five levels of permissions, from operator to director, to manage access to different modules and data.
- Activity Logging: Comprehensive logging of user actions and data modifications to ensure full traceability and accountability.
- Bilingual Support: Support for both French and Arabic languages, with dual-language display for titles and labels to cater to a diverse user base.

## Style Guidelines:

- Primary color: Strong, health and safety oriented green (#4CAF50), to communicate that the application is focused on safety, as well as growth and forward movement.
- Background color: A very light, desaturated green (#F1F8E9) to provide a calm and unobtrusive backdrop that doesn't conflict with data visualizations.
- Accent color: A deep, attention-grabbing blue (#3F51B5), chosen for its position as an analogous color and used for interactive elements, calls to action, and important notifications.
- Headline font: 'Space Grotesk' (sans-serif) for a modern and technical look.
- Body font: 'Inter' (sans-serif) for clear and readable content. 
- Use a consistent set of minimalist icons to represent different HSE processes and data points.
- Employ a clear, tabbed navigation system for easy access to different modules, with simple color-coded indicators to highlight important information.
